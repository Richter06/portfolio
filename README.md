# 💻 Portfólio - Richard R. Araújo

Este é o meu site de portfólio pessoal, desenvolvido com foco em apresentar meus projetos, habilidades e evolução como desenvolvedor Front-End.

---

## 🚀 Sobre o projeto

O portfólio foi criado para demonstrar minhas habilidades em desenvolvimento web, com foco em:

- Interface moderna e responsiva
- Experiência do usuário (UX)
- Organização semântica do HTML
- Animações e interações com JavaScript
- Apresentação clara de projetos e skills

Além disso, o site inclui elementos visuais como slider de projetos, modal de imagens, animação de habilidades e partículas dinâmicas de fundo.

---

## 🧠 Tecnologias utilizadas

- HTML5 (semântico)
- CSS3 (responsividade e animações)
- JavaScript (interatividade)
- tsParticles (efeito visual de fundo)
- Git & GitHub (versionamento)

---

## 📌 Funcionalidades

- 📷 Slider de projetos com navegação automática e manual  
- 🖼️ Modal para visualização ampliada de imagens  
- 👤 Seção “Quem sou eu” interativa  
- 📊 Animação de barras de skills ao scroll  
- ✨ Fundo animado com partículas  
- 📱 Totalmente responsivo para mobile  

---

## 🎯 Objetivo

Este projeto tem como objetivo servir como portfólio profissional para demonstrar minhas habilidades em Front-End e atrair oportunidades de freelancer ou estágio na área de desenvolvimento web.
